# Free AI Automation Tools for Small Businesses

Free, browser-based tools and open datasets that help small and mid-sized businesses plan AI automation, estimate ROI and get found in AI search. Built and maintained by [313 Automations](https://313automations.com/?utm_source=github&utm_medium=repo&utm_campaign=free-tools), an AI automation, web and SEO/GEO agency in Lahore, Pakistan (since 2018).

All tools run entirely in your browser: no sign-up, no tracking of your answers, nothing stored.

## Tools

| Tool | Live demo | What it does |
|---|---|---|
| AI Readiness Checker | [Open](https://huggingface.co/spaces/313Automations/ai-readiness-checker) | 10 questions scoring processes, data, tools, team and goals; recommends your first automation |
| AI Use Case Finder | [Open](https://huggingface.co/spaces/313Automations/ai-use-case-finder) | Filter practical AI automation use cases by industry, team and complexity |
| AI Chatbot ROI Calculator | [Open](https://huggingface.co/spaces/313Automations/chatbot-roi-calculator) | Estimate hours saved, net monthly savings and payback for a support or sales chatbot |
| Automation Tool Picker | [Open](https://huggingface.co/spaces/313Automations/automation-tool-picker) | Zapier vs Make vs n8n vs custom code, matched to your team and workflows |
| GEO Readiness Checklist | [Open](https://huggingface.co/spaces/313Automations/geo-readiness-checklist) | 20 checks to see how ready your site is to be cited by ChatGPT, Perplexity and AI Overviews |
| Local Business Schema Generator | [Open](https://huggingface.co/spaces/313Automations/local-business-schema-generator) | Generate LocalBusiness JSON-LD with address, hours, coordinates and sameAs |

Source code for each tool is a single self-contained HTML file (no build step), available under **Files** on each Hugging Face Space.
